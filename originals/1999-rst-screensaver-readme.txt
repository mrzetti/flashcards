RAMMSTEIN screensaver
_____________________________________
DEUTSCH
WINDOWS-SYSTEM-VORAUSSETZUNGEN
Windows 95/98/(NT4.0)
Pentium @ 90mhz
10mb freier Arbeitsspeicher
16-bit Graphik @ 800x600 pix

INSTALLATION
1.) Zum installieren bitte das Programm 
"RST_instal.exe" ausfuhren. Alle notwendigen 
Dateien werden installiert.
2.) Der Screensaver lasst sich in der Windows
Systemsteuerung unter "Anzeige" konfigurieren
oder deaktivieren.
3.) Der Screensaver lasst sich durch entfernen
der Dateien "RST_saver.exe" und "RST_saver.scr"
aus dem WINDOWS-ROOT deinstallieren.

_____________________________________
ENGLISH
WINDOWS-SYSTEM-REQUIREMENTS
Windows 95/98/(NT4.0)
Pentium @ 90mhz
10mb free RAM
16-bit Graphics @ 800x600 pix

INSTALLATION
1.) To install the screensaver just doubleclick
the file named "RST_inst.exe". All nessesary
files will be installed to your system.
2.) To configure or deaktivate the screensaver
open it from your controlpanels.
3.) To de-install the screensaver remove the
files "RST_saver.exe" and "RST_saver.scr"
from your WINDOWS-ROOT.
